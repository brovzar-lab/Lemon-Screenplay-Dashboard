# The 11 Passes - Detailed Guide

Each pass focuses on 4-5 specific problems. Don't try to fix everything at once.

## 1. Foundation Pass - Strengthening the Core

**Purpose:** Align character, theme, plot, and basic structure

**Key Areas to Address:**
- Theme: What is your story about in ONE WORD? (redemption, love, betrayal, etc.)
- Main Character's Internal Story: Lives in crisis, clear emotional flaws
- Main Character's Want: External goal stated early (by end of Act 1)
- Plot: Tie plot events to character's internal story
- Main Plot Problem: Difficult problem introduced that drives the screenplay
- Structure: Does it support character's story? Can you start later for urgency?

**What to Focus On:**
- Make the main character's journey the center of everything
- Use plot to pressure character's emotional issues
- Align all major elements (character, theme, plot)
- Don't worry about dialogue yet - let characters talk

**Common Fixes:**
- If plot feels episodic → tie events to character's internal journey
- If theme is unclear → state it clearly and repeat through character/plot
- If structure drags → compress time, start later

---

## 2. Character Pass - The Emotional Core

**Purpose:** Solidify main character's internal story and arc

**Key Areas to Address:**
- Internal Character Story: Clear traceable arc from beginning to end
- Lives in Crisis: Both external AND internal crises
- Want vs. Need: What they pursue vs. what they actually require
- Character Flaws: Relatable, identifiable flaws that get pressured
- Sounding Board Character: Someone main character can confide in/be confronted by
- Active vs. Passive: Main character must FORCE the action

**What to Focus On:**
- Create scenes that reveal character's emotional issues
- Make character consistent until motivated to change
- Use relationships to show different facets of character
- Create defining scenes that capture who they are

**Common Fixes:**
- "I don't like the main character" → Add relatable flaws, show them trying
- "Best friend is more interesting" → Give main character deeper issues
- "Main character is vague" → Create defining scene, clarify want/need
- "Too passive" → Make them force action, pursue their want actively

**Remember:** Character is ridiculously hard. This is the FOUNDATION.

---

## 3. Story and Theme Pass - The Emotional Underpinning

**Purpose:** Weave emotional threads, align all stories with theme

**Key Areas to Address:**
- Know Your Story: Reduce to ONE WORD, make it consistent
- Theme Consistency: Restate through characters and plot repeatedly
- Main Character's Emotional Journey: At the heart of everything
- Multiple Stories: Supporting characters' stories orbit main character's story
- Stakes: Personal consequences if main character fails

**What to Focus On:**
- Link supporting characters' stories to main character's journey
- Use plot to pressure main character's internal story
- Each character either supports or opposes main character's goal
- Theme must resonate throughout (like a musical score)

**Common Fixes:**
- "I don't understand what it's about" → Clarify theme, restate it consistently
- "Not emotionally involved" → Raise personal stakes, deepen character issues
- Multiple storylines disconnected → Tie them all to main character's journey

---

## 4. Structure Pass - Architecture and Design

**Purpose:** Tighten and focus structure, find your spine

**Key Areas to Address:**
- The Spine: 25-30 words describing what the movie is about
- Scene Order: Is this the most effective sequence?
- Sequences and Scene Groups: Organize into cohesive units
- Time Usage: Compress or extend time strategically
- Three-Act Questions: First act sets up third act resolution

**What to Focus On:**
- Eliminate anything that doesn't support your spine
- Enter scenes late, exit early
- Use sequences (groups of scenes working toward mini-goals)
- Tighten openings - can you start later?

**Common Fixes:**
- Structure feels loose → Find your spine, cut what doesn't serve it
- Third act doesn't work → Look to first act, ensure proper setup
- Pacing drags → Compress time, combine scenes, start later

---

## 5. Plot Pass - Cause and Effect

**Purpose:** Create character-centric plot events with cause/effect

**Key Areas to Address:**
- Plot and Character Link: Change character = change plot
- Main Plot Problem: Difficult (impossible?) to solve
- Cause and Effect: Each event leads logically to the next
- Central Dramatic Conflict: Main character vs. antagonist
- Active Main Character: They force action, not react to it
- Plot Questions: Create questions audience wants answered

**What to Focus On:**
- Use character's want to create plot events
- Make plot pressure character's emotional issues
- Antagonist's plan drives complications
- Raise stakes progressively

**Common Fixes:**
- "Plot is episodic" → Strengthen cause/effect, tie to character journey
- "Not exciting enough" → Increase conflict, add reveals/reversals
- "Feels predictable" → Create unexpected complications, stronger antagonist

**Use Index Cards:** Physically move scenes around to test new structures

---

## 6. Complications Pass - Making Life Much More Difficult

**Purpose:** Add obstacles, reveals, reversals - increase tension

**Key Areas to Address:**
- Complications: Make situations messier and more difficult
- Obstacles: Physical, psychological, emotional roadblocks
- Reveals: Information held back then disclosed for impact
- Reversals: Sudden changes that force character to adjust
- Suspense: Withhold information to create tension

**What to Focus On:**
- Make main character's journey increasingly difficult
- Add peaks and valleys - create a roller coaster
- Hold back information strategically
- Each complication should pressure character's flaws

**Common Fixes:**
- "Screenplay is slow" → Add obstacles, create reveals/reversals
- "Feels repetitious" → Vary challenges, increase difficulty
- "Second act drags" → More complications in the middle

---

## 7. Relationship Pass - Interconnecting

**Purpose:** Deepen all major relationships, create arcs

**Key Areas to Address:**
- Ties That Bind: What connects these characters?
- Relationship Tension: Each relationship needs specific tension
- Positive vs. Negative: Characters either support or oppose
- Relationship Arcs: Relationships must change over the screenplay
- Dysfunctional Dynamics: Great screenplays have messy relationships

**What to Focus On:**
- Love interest must have their own story (not cardboard)
- Use relationships to reveal character depth
- Create authentic tension in each relationship
- Show how relationships complicate main character's journey

**Common Fixes:**
- "Love interest isn't interesting" → Give them emotional story and arc
- "Not enough conflict" → Make relationships more dysfunctional
- Characters feel flat → Deepen their relationships

---

## 8. Scene Pass - Link and Connect

**Purpose:** Ensure each scene contributes, link them cohesively

**Key Areas to Address:**
- Scene Point: Each scene has ONE clear purpose
- Scene Tension: Every scene needs tension/conflict
- Scene Structure: Rising/falling action, enter late/exit early
- Emotional Roller Coaster: Peaks and valleys scene to scene
- Link and Connect: Each scene builds on the previous
- Show Don't Tell: Action over exposition

**What to Focus On:**
- Can state the point of each scene clearly
- Characters consistent scene to scene
- Trim heads and tails (enter late, exit early)
- Use unique locations effectively
- Tighten excess dialogue and description

**Common Fixes:**
- "Screenplay is flat" → Add scene tension, create emotional beats
- "Nothing seemed to happen" → Clarify scene points, increase stakes
- "Scenes feel long" → Cut heads/tails, focus on ONE point per scene

---

## 9. Dialogue Pass - Rhythm and Flow

**Purpose:** Make dialogue character-specific, efficient, natural

**Key Areas to Address:**
- Character Voice: Each character speaks uniquely
- Subtext: What's NOT said is often more powerful
- Rhythm: Natural flow, fragments not full sentences
- Efficiency: Say more with less
- Avoid Exposition: Don't tell what can be shown

**What to Focus On:**
- People speak in fragments, not complete sentences
- Create space between lines
- Each character has distinct attitude reflected in speech
- Cut speeches down - less is more

**Common Fixes:**
- "All characters sound the same" → Give each specific attitude/philosophy
- "Dialogue doesn't seem real" → Make it less formal, add fragments
- "Too expository" → Show through action, use subtext

**Remember:** Don't focus on dialogue too early. Save for later passes.

---

## 10. Consistency Pass - Quality Control

**Purpose:** Ensure consistency across all elements

**Key Areas to Address:**
- Touchstone: Reconnect with original inspiration
- Character Consistency: Behavior consistent until motivated to change
- Theme Consistency: Same theme beginning to end
- Tone Consistency: Established on page 1, maintained throughout
- Plot Consistency: No dropped storylines or plot holes
- Attitude Consistency: Characters' attitudes stay consistent

**What to Focus On:**
- Characters can only change when motivated by story
- Theme must be restated consistently
- Tone set early must be maintained
- Track all storylines to resolution

**Common Fixes:**
- "Main character keeps changing" → Ensure consistency, motivate changes
- "Story seemed to wander" → Reconnect to touchstone, strengthen theme
- "Tone unclear" → Establish clearly on page 1, maintain throughout

---

## 11. Polish Pass - Dialogue, Text, and Tightening

**Purpose:** Final cleanup, tightening, professional finish

**Key Areas to Address:**
- Script Length: 100-120 pages maximum
- Tightening Dialogue: Cut repetitive lines
- Trimming Text: Thin out descriptions
- Making Big Cuts: Kill your darlings
- Stall Scenes: Cut scenes that don't move story forward
- Heads and Tails: Enter scenes late, exit early
- Spelling and Grammar: Professional quality control

**What to Focus On:**
- Every word must justify its existence
- Look for entire scenes to cut (bigger impact than word trimming)
- Read cover-to-cover one final time
- When in doubt, cut it

**Common Fixes:**
- "Script feels long" → Cut stall scenes, trim dialogue, make big cuts
- "Slow spots" → Identify and eliminate, trim scene heads/tails
- Spelling/grammar errors → Clean everything up

**Motto:** "When in doubt, cut it."

---

## Pass Selection Strategy

**You don't do all 11 passes every time.** Select based on your notes:

**If notes are about character:**
→ Character Pass + Relationship Pass

**If notes are about structure/pacing:**
→ Structure Pass + Scene Pass

**If notes are about stakes/excitement:**
→ Plot Pass + Complications Pass

**If notes are vague "something's off":**
→ Foundation Pass first, then reassess

**Always finish with:**
→ Consistency Pass + Polish Pass

**Start with character unless there's a clear structural crisis.**
